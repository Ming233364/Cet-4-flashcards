# CET-4 标准词库单词卡

一个纯前端、可离线运行的 CET-4 词汇学习应用：**4545 词**（覆盖 CET-4 大纲词汇），每个词都有**英 / 美双音标**、中文释义、例句与常用搭配，并按真题考频标注 **1–5 星**；近三年真题中出现过的词带**「近三年真题」徽标**。内置四种基本题型、词组搭配题、周测 / 月测滚动抽查与学习数据统计。

> 无需安装。双击 `index.html`（多文件版）或 `cet4-flashcards.html`（单文件版）即可使用；不联网也能背词和做题，**英美发音音频需要联网**（使用在线标准发音）。**v2.1 起手机 / 平板 / 电脑自适应**；**v2.3 新增词性转换、地道表达、标准英美音频、多选题型、自定义题量与拼写提示**。

### 更新桌面上的旧版本（Windows）
- 双击本目录的 `更新到桌面.cmd`：会把 v2.3 的页面、脚本、样式和说明覆盖到 `%USERPROFILE%\Desktop\cet4-flashcards`，并把 `cet4-flashcards-v2.3-mobile.zip` 复制到桌面。
- 也可以直接解压 `cet4-flashcards-v2.3-mobile.zip`，用里面的 `cet4-flashcards.html` 替换旧文件。

## 功能一览

### 学习卡片
- **4545 词标准词库**：按 CET-4 三份大纲词表合并去重，覆盖 A–Z。
- **英美双音标**：每个单词分别标注 US / UK 音标，点击 🔊 分别播放美音、英音。音频来自在线标准发音（有道词典发音接口），不使用浏览器自带的机器合成音；离线时单词卡与测试仍可用，仅发音不可用。
- **考频星级**：按 36 套历年真题 + 近三年 15 套真题的词频综合排序，分为 5★（最高频，约前 10%）、4★、3★、2★、1★（未在真题中出现）；卡片正反面均显示星级徽标。
- **近三年真题标记**：2023-12、2024-06、2024-12、2025-06、2025-12 共 15 套真题中出现过的词显示红色「近三年真题」徽标，悬停可看具体场次与总出现次数。
- **词性转换**：卡片背面列出 1–4 个同词族派生形式、词性与中文释义（如 able → ability n. 能力），无派生形式的虚词显示“暂无词性转换”。
- **地道表达**：常用词补充 1–2 条英美地道表达（英文 + 中文），如 `make up one's mind`。
- **中文释义**：1–3 条高频中文释义，按词性标注（v. / n. / adj. …）。
- **用法举例**：每个词至少 1 条英文例句 + 中文翻译，例句中的目标词自动高亮；常用搭配按星级扩充到最多 4 条（5★/4★ 优先），并有中文。
- **卡片 3D 翻转**：正面看单词、音标、星级；翻面看释义、例句、搭配。
- **掌握标记**：不认识 / 有点印象 / 认识 三档；侧栏实时显示进度、各状态数量、收藏数、近三年真题词数、已测词数。
- **打开顺序**：每次刷新/打开页面，卡组按「有点印象 → 不认识 → 未学习 → 认识」排列，同组内按字母序；「认识」的词排在最后，优先复习模糊词。
- **动态归类**：练习中「认识」的词累计答错 3 次自动移入「有点印象」；「有点印象」累计答错 2 次移入「不认识」，并清空该词的答题记录与错题本计数；手动改标记也会重置累计计数。
- **收藏**：一键收藏重点词，可按「已收藏」筛选。
- **检索与筛选**：按单词或中文释义搜索；按首字母、学习状态、考频星级筛选；可只看近三年真题词；支持随机打乱。
- **键盘操作**：`←` `→` 切换、`空格` 翻面、`1/2/3` 标记、`S` 美音、`D` 英音、`F` 收藏。

### 词汇测试（四种基本题型 + 词组搭配）
| 模式 | 题型 | 说明 |
| --- | --- | --- |
| 英译中 | 看单词选释义 | 4 选 1，题干附英美音标 |
| 中译英 | 看释义选单词 | 4 选 1 |
| 听音选词 | 听发音选单词 | 自动朗读，可点 🔊 重听 |
| 拼写挑战 | 看释义拼单词 | 输入拼写，3 次分级提示；可点 🔊 听标准发音 |
| 词组搭配 | 看中文搭配选英文词组 | 题干不出现目标词；4★ 以上词条加考 |
| 短语英译中 | 看英文短语选中文 | 4★ 以上词条的常用搭配 |
| 短语听音选词 | 听短语选英文 | 4★ 以上词条的常用搭配 |

- **测试模式可多选**：英译中 / 中译英 / 听音选词 / 拼写挑战可任选一种或多种；多选时混合出题。选「英译中」或「听音选词」时，4★ 以上词条会自动混入相关短语英译中 / 短语听音题。
- **题量自定义**：普通测试可输入 1–2000 题；周测/月测输入的是抽查词数（周测 ≤350 词、月测 ≤750 词，对应题数上限 700 / 1500）。
- 出题范围：全部、★★★★★ 最高频、近三年真题、已收藏、错题本、周测、月测。
- **周测 / 月测（滚动抽查）**：取近 7 / 30 天有学习记录（标记或答题）的词；4★ 以上全部纳入并加考常用词组；其余名额按「不认识 60% / 错题 20% / 有点印象 15% / 认识 5%」抽取；每词至少 2 种题型，1–2★ 不考拼写，3★ 不考拼写、保留中译英，并保证四种基本题型至少各出现一次。连续两次周测会优先避开上一轮出现过的词；词不够时允许复用单词，但避开上一轮用过的题型。周测最多 350 词 / 700 题，月测最多 750 词 / 1500 题。
- 即时反馈：正确/错误、词义、考频星级、真题场次、正确答案；**答对后约 0.9 秒自动进入下一题**，答错停留查看解析。支持键盘 `1–4` 作答、`Enter` 下一题。
- **拼写提示**：每个单词限 3 次。第 1 次显示首字母；第 2 次显示单词字母数量；第 3 次可选「提示整个单词」（直接记错并加入错题）或「提示奇数位字母」（从左到右第 1/3/5… 位显示字母）。选择奇数位提示后 10 秒内未拼对，自动记错、加入错题并跳到下一题。
- 测试结束显示正确率圆环、得分统计、错题清单；并会按每个单词本轮的全部作答自动更新掌握标记：全对 → 认识，全部答错 → 不认识，其余 → 有点印象。可「再测一次」「只练错题」。
- 答错自动进入**错题本**，之后答对会逐步移出；触发动态降级时该词答题记录清零；测试历史保留最近 20 次。

### 学习数据
- 已掌握数量与占比、测试次数、累计正确率、收藏数、近三年真题词数、五星词数。
- 错题本按错误次数排序；最近测试记录（模式、题数、正确率、时间）。
- 一键清空所有学习数据（不影响词库文件）。

### 其他
- 深色 / 浅色主题切换，跟随系统偏好，选择会记忆；手机浏览器地址栏颜色同步主题。
- **手机 / 平板 / 电脑自适应**：手机端底部导航、安全区适配、触控尺寸、左右滑动切词；平板与桌面保持双栏布局。
- 学习进度、收藏、错题、历史、主题全部保存在浏览器 `localStorage`，刷新不丢失。

## 手机 / 电脑兼容说明

### 手机端
- 屏幕宽度 ≤ 720px 时，主导航自动变为**底部标签栏**（学习 / 测试 / 数据），方便单手操作。
- 卡片支持**左右滑动**切换上一个 / 下一个单词；**轻点卡片**翻面；卡背可上下滚动查看释义、例句与搭配。
- 适配 iPhone 刘海屏和底部手势条（`viewport-fit=cover` + `env(safe-area-inset-*)`），横屏时自动压缩布局并恢复顶部标签。
- 所有按钮触控高度 ≥ 44px；搜索框和下拉框使用 16px 字号，避免 iOS 聚焦时自动放大页面。
- 深色模式下会同步手机浏览器状态栏 / 地址栏颜色。
- 发音仍使用浏览器语音合成：首次点 🔊 需要一次用户点击（iOS/Android 均如此）；如果系统没有英式语音包，英音会回退为默认英语。

**在手机上打开**：把 `cet4-flashcards.html` 单文件发送到手机，用 Chrome / Edge / Safari 打开即可；也可以把整个文件夹放到任意静态网站/局域网服务器，访问 `index.html`。部分手机浏览器不允许直接打开本地 HTML，此时用文件管理器选择“用浏览器打开”，或使用静态服务器。

### 电脑端
- 原有双栏布局、3D 翻卡、键盘快捷键（`←` `→` 空格 `1/2/3` `S` `D` `F`）全部保留。
- 窗口缩到平板/手机宽度时自动切换为单栏和底部导航；放大回桌面宽度恢复原布局。
- 手机和电脑的学习进度各自保存在本机浏览器，不会自动跨设备同步。

## 快速开始

**方式一：单文件版（推荐分享/存档）**

双击 `cet4-flashcards.html`。CSS、4 个 JS（词库 + 逻辑）全部内联在一个 HTML 中，只有这一个文件也能用。

**方式二：多文件版（推荐开发/修改时使用）**

直接双击打开 `index.html`。所有脚本均为普通 `<script>`，`file://` 协议下可直接运行。

> 建议使用较新的 Chrome / Edge。发音依赖浏览器语音合成：美音使用 `en-US` 语音，英音使用 `en-GB` 语音；若系统未安装英式语音包，英音可能回退为默认英语发音（音标不受影响）。

## 开发与校验

需要 Node.js ≥ 18（本机 Node 未加入 PATH 时可用绝对路径调用）。

```bash
# 校验词库：字段完整性、音标、释义、例句/短语数量、星级、真题字段、与词表一致性、A/B 重复
node tools/validate-data.js

# 静态 UI 契约：脚本顺序、id 引用、data-* 取值、动态类是否有样式
node tools/check-ui.js

# 真实词库出题集成检查：4 种模式 × 4545 词 + 周测混合题，校验选项/答案/范围联动
node tools/check-quiz.js

# 核心逻辑单元测试（29 项，纯 Node，无需浏览器）
node tests/core.test.js

# 重新生成单文件版 cet4-flashcards.html
node tools/build-single.js

# 串行跑完上面全部检查并打包
node tools/validate-data.js && node tools/check-ui.js && node tools/check-quiz.js && node tests/core.test.js && node tools/build-single.js
```

若使用 npm，上述命令也配置在 `package.json` 的 `validate` / `check:ui` / `check:quiz` / `test` / `build` / `check` 脚本中。

`tests/core.test.js` 覆盖：数据标准化与去重、星级/真题字段归一化、标记/收藏/统计、localStorage 持久化、答题与错题本增减、四种出题模式、出题范围（收藏/错题/五星/近三年真题/空范围）、星级与真题筛选、搜索与首字母筛选（含「全部字母」）、测试历史上限、重置逻辑、题库不足、脏存储清洗与非法输入等边界；v2.2 新增卡组排序、周测/月测的 lastSeen 与 7/30 天抽样、4★ 全纳入与星级题型限制、词组题型、动态降级与重置计数；v2.3 新增词性转换/地道表达字段、多选模式题数、周测去重、短语题不泄词、拼写提示与自动跳题。

`tools/check-quiz.js` 用真实词库为四种题型各生成一轮全覆盖测验，逐题校验选项数量与去重、正确答案存在、拼写题无选项、收藏/已掌握/五星/真题范围过滤是否生效；另检查周测/月测的综合题、词组题、短语英译中/听音题与 4★ 覆盖、多选模式题数。

## 词库构建与扩充

词库由 `tools/build_vocab.py` 从以下开源语料生成（原始文件在 `.work/`，不随发布包提供）：

| 数据 | 来源 | 用途 |
| --- | --- | --- |
| CET4_1/2/3_sentence.json | [KyleBing/dict](https://github.com/KyleBing/dict) | 单词、英美音标、释义、例句、短语（三份并集 4544 词） |
| cet4_words.csv | [cduang/word-statistics-cet4](https://github.com/cduang/word-statistics-cet4) | 2006–2017 年 36 套真题词频，用于星级排序 |
| papers/*.txt | [catteacher0515/cet4-download](https://github.com/catteacher0515/cet4-download) | 近三年 15 套真题文本，用于「近三年真题」标记 |

构建规则：
- 三份词表按小写单词并集去重；原数据拼写错误 `cigaret`、`reservior` 剔除，旧版精编词条覆盖对应条目，并补回 `satisfy`、`wonder`、`yell`，最终 **4545 词**。
- 音标统一为 `/…/`，取第一读音，`'`→`ˈ`、`ɹ`→`r`、`ɚ`→`ər`；缺失音标用 dictionaryapi.dev 缓存与人工表补齐。
- 星级：`score = 36 套词频/36 + 近三年 15 套词频/15`（按词形变体归并）；未出现 → 1 星；出现过的按分数排序，前 10% 为 5 星、10–25% 为 4 星、25–50% 为 3 星，其余 2 星。
- 真题标记：分别统计 5 个场次（2023-12、2024-06、2024-12、2025-06、2025-12），命中的场次写入 `examYears`，`examCount` 为 15 套总出现次数。
- 例句：每个词最多保留 2 条；原始语料中 131 个无例句的词条，由 `tools/example-fixes.json` 补入人工撰写的 1–2 条例句。
- 输出每条一行 JSON，A/B 两组按字母顺序平分。

当前构建统计：5★ 315、4★ 471、3★ 786、2★ 1571、1★ 1402；近三年真题词 2602；所有词均有英美音标与至少 1 条例句。

如只需小幅增删词条：

1. 按 `tools/DATA_SPEC.md` 的格式修改 `js/data-a.js` / `js/data-b.js`（每条一行合法 JSON，行尾逗号）。
2. 同步修改 `tools/words-a.txt` / `tools/words-b.txt`（校验脚本会逐词比对顺序）。
3. 运行 `node tools/validate-data.js`，通过后运行 `node tools/build-single.js` 重新打包。

数据字段：

```json
{"word":"abandon","us":"/əˈbændən/","uk":"/əˈbændən/","pos":["v."],"senses":[["v.","放弃；抛弃"]],"examples":[["They had to abandon the plan.","他们不得不放弃这个计划。"]],"phrases":[["abandon oneself to","沉溺于"]],"star":3,"examYears":["2024-06","2025-06","2025-12"],"examCount":5}
```

要求：`star` 为 1–5 整数；`examYears` 为 `["YYYY-MM"]` 数组（可为空）；`examCount` 为非负整数；`examples` 0–2 条，`phrases` 0–2 条。

## 说明与限制

- **词库规模**：4545 词，接近 CET-4 大纲 4500 词要求；不同年份大纲版本略有差异，个别超纲/派生词可能包含在内。
- **星级口径**：综合 36 套历史真题与近三年 15 套真题词频，按分位数分档，是「考频代理指标」，不等同于官方词频表；`examCount` 统计的是 15 套真题文本中的出现次数（含题干、选项、阅读原文，不含听力音频稿）。
- **音标**：采用牛津 / 朗文通用标注，多音词只取最常用读音；英美同音词两个字段也会分别填写。
- **例句**：主要来自开源词库；原始语料缺少例句的 131 个词条已用 `tools/example-fixes.json` 中的简短例句补齐；个别例句较简单，已清洗无中文翻译的脏数据。
- **发音**：由系统语音合成提供，音质取决于操作系统语音包；英音在缺少 `en-GB` 语音时会回退。
- 学习数据仅保存在**当前浏览器本机**，清理浏览器数据会一并清除；不同浏览器/设备之间不互通。
- 本项目无任何第三方运行时依赖，可整目录拷贝离线使用。
